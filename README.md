# 🎧 AWAAZ – The Sound of Desi Hip-Hop

AWAAZ is a Spotify-inspired, browser-based music streaming and playlist management application dedicated to the Desi Hip-Hop (DHH) community.

## Features

- Desi Hip-Hop music discovery
- Song, artist, and album search
- Music player with playback and volume controls
- Favorite songs management
- Custom playlist creation
- Browser-based data persistence
- Responsive dark-themed interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Audio API
- Browser Local Storage

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Explore the music library, create playlists, and save favorites.

**Note:** Audio playback requires authorized audio files placed in the `songs/` directory with filenames matching the paths in `script.js`. Commercial audio files are not included in this repository.

## Project Architecture

The application follows a client-side architecture:

User Interface → JavaScript Logic → HTML5 Audio API / Local Storage
